## 4. 待决策：面试题来源 URL 口径

原 plan §C2 写"答案须附官方来源 URL"，但实际 97% 无 URL。两种口径：

- **口径 A（锚定知识树，推荐）**：选择题 explain / 简答 / 手答题答案，只要事实正确且对应知识点有来源 URL 即合规；仅对"有唯一权威出处且易过期"的点（API 版本、配置项、命令参数）补官方 URL。优点：避免 6565 题逐条注水式补 URL，聚焦事实正确性。
- **口径 B（每条补 URL）**：严格按 plan 字面，给 6565 题全部补官方来源 URL。成本高、多数概念性题无单一 URL，性价比低。

> 建议口径 A；如选 B，仅对 VIP/手写题子集补 URL。请确认。
