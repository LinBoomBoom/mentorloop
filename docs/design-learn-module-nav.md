# 学习中心模块导航改版设计稿 v4（最终版）

> 版本：2026-08-17（v4，移动端方案 C 全屏方向入口确认为最终方案）  
> 范围：仅设计稿，不改代码  
> 目标：解决“模块首页不展示内部技术方向、模块页章节全部摊开难找”的问题，并适配移动端

---

## 1. 现状问题

### 1.1 学习中心首页
- 模块卡片只展示标题、描述、章/节总数。
- 用户无法一眼感知“前端开发”内部包含 HTML/CSS、JavaScript、React、Vue、工程化等具体技术方向。

### 1.2 模块详情页
- 进入模块后，所有章节卡片默认展开/平铺。
- 前端 70 章 298 节全部摊开，想专门看某个技术方向需要大量滚动。

---

## 2. 最终设计方案

### 2.1 桌面端：顶部方向卡片式

**位置**：模块标题、描述、搜索框下方。

**形式**：
- 横向排列的“方向卡片”，尺寸约 132×72px。
- 每张卡片包含：左侧彩色小方块图标、方向名称、章节/小节计数。
- 默认第一张为“全部”，显示模块总章数/总节数。
- 超出视口宽度时横向滚动。

**状态**：
- **激活**：左侧 4px 品牌色竖条 + 浅珊瑚背景 + 深色文字。
- **未激活**：白底、0.5px 灰边框、彩色图标 + 深灰文字。
- **Hover**：边框变 brand-coral/40，轻微上浮。

---

### 2.2 移动端：全屏方向入口（方案 C，最终确认）

#### 页面 1：方向选择页

**进入方式**：从学习中心首页点击模块卡片，或从其他页面进入 `/learn/[module]`。

**布局**：
- 顶部：面包屑“学习中心 / {模块名}”。
- 标题：“选择技术方向”。
- 副标题：“先选一个方向，再专注学习该方向下的章节”。
- 方向网格：2 列卡片布局。

**方向卡片**：
- 尺寸：约 140×84px，圆角 14px。
- 内容：左侧 24×24px 彩色圆角方块图标 + 方向名称 + 章节/小节计数。
- 卡片间距：水平 12px，垂直 12px。
- 包含“全部”选项，显示模块总章数/总节数。

**交互**：
- 点击任意方向卡片 → 进入该方向的章节列表页。
- 无额外按钮，纯卡片选择。

#### 页面 2：章节列表页

**进入方式**：从方向选择页点击某个方向进入。

**顶部导航栏**：
- 左侧：“‹ 方向”返回按钮，点击返回方向选择页。
- 中间：当前方向名称（如“Web 基础”）。
- 右侧：“搜索”入口，点击展开搜索框。

**当前方向信息条**：
- 位置：导航栏下方。
- 内容：彩色图标 + 方向名称 + 章节/小节计数。
- 右侧：“切换”文字链接，点击返回方向选择页。

**章节列表**：
- 只展示当前方向下的章节。
- 保持现有章节卡片样式：序号、标题、goal 描述、节数、小节列表。
- 支持折叠/展开。

**与桌面端差异**：
- 移动端把“选方向”和“看章节”拆成两个页面，避免顶部筛选条占用纵向空间。
- 桌面端在同一页面内完成筛选与浏览。

---

### 2.3 学习中心首页：模块卡片直接展示技术方向

**位置**：模块卡片描述文字下方、章/节计数上方。

**形式**：
- 使用“小圆点 + 文字”的轻标签形式。
- 圆点颜色与模块主题色一致。
- 每行最多 3 个，最多展示 6 个 + `+N`。
- 点击方向标签 → 进入该模块方向选择页，并自动定位到对应方向（移动端）；或进入模块页并选中对应方向（桌面端）。

**示例**：
- 前端开发：HTML/CSS · JavaScript · React / Vue · 工程化 · 性能优化 · +3

## 4. 数据需求

当前 `chapters` 表字段：

```
id, module_id, title, goal, position
```

**缺少方向字段**。实现本设计稿时，需要为章节补充方向分类。

### 推荐方案：新增 `subtrack` 字段
- 在 `chapters` 表新增 `subtrack TEXT`。
- 与 `interview_questions`、`roadmap` 的 `subtrack` 概念对齐，形成统一的技术方向体系。
- 新增 `module_subtracks` 配置表（或硬编码配置），记录每个模块包含哪些方向、方向的颜色/图标/顺序。

## 5. URL 与交互状态

### 5.1 首页模块卡片标签链接

```
/learn/frontend?subtrack=react
```

### 5.2 桌面端模块页

- 点击方向卡片时，URL 增加/更新 `subtrack` 参数。
- 章节列表在同一页面内过滤。

### 5.3 移动端模块页

- 进入 `/learn/frontend`：显示方向选择页。
- 点击方向后进入 `/learn/frontend?subtrack=web`：显示该方向章节列表页。
- 顶部“‹ 方向”返回 `/learn/frontend`（方向选择页）。
- 支持从 URL 直接进入某个方向的章节列表页。

### 5.4 搜索

- 桌面端：搜索框在页面顶部，placeholder 为“在 {方向} 中搜索…”。
- 移动端：搜索入口在章节列表页顶部导航栏，点击后展开搜索框。

## 6. 响应式适配总结

| 断点 | 首页模块卡片 | 模块页方向筛选 |
|------|-------------|---------------|
| ≥1024px | 2×2 卡片，方向标签固定展示 | 顶部方向卡片条，横向滚动，同页过滤 |
| 640–1023px | 2 列卡片，方向标签固定展示 | 顶部方向卡片条，横向滚动，同页过滤 |
| <640px | 单列卡片，方向标签固定展示 | 全屏方向入口 → 章节列表页 |

## 7. 验收标准

- [ ] 学习中心首页每个模块卡片直接展示技术方向标签。
- [ ] 桌面端模块页顶部为方向卡片条，切换后同页过滤章节。
- [ ] 移动端进入模块后先看到方向选择页（2 列卡片网格）。
- [ ] 移动端点击方向后进入章节列表页，顶部显示当前方向与返回入口。
- [ ] 章节列表页显示当前方向下的章节计数。
- [ ] URL 参数可保存并分享当前方向筛选状态。
- [ ] 首页方向标签可深链到对应方向。
