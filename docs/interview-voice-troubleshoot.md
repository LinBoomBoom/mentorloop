# 面试语音/视频 · 本机排障与落地指南

> 适用：本地 `npm run dev` 调试 AI 模拟面试的语音（TTS 音色、重播）与麦克风（STT）问题。
> 结论先行：**不需要安装任何第三方付费插件。** 推荐路径是**服务端本地 Piper 离线神经网络 TTS**（一次下载，永久离线、所有访客一致）。

## 一、推荐方案：本地 Piper 离线神经网络 TTS（首选）

云端 Edge TTS（微软）在多数公司/校园/运营商网络下会被拦截（实测 `403 Unexpected server response`，**换 VPN 无用**——是你的网络到不了微软这个端点，或微软风控拒了免费端点）。所以**不要把面试语音依赖云端**。

改为**服务端本地 Piper**：C++ 推理引擎 + 中文神经网络模型，完全离线，所有浏览器听到的一致好声音，永不 403。

### 一键安装（只需一次）
```bash
npm run setup:piper
```
脚本会：
1. 按你的系统（Windows / macOS / Linux）下载对应的 Piper 二进制到 `data/piper/`；
2. 下载 3 个中文神经网络模型（华嫣 / 小雅 女声、朝文 男声）到 `data/piper/models/`；
3. 二进制与模型**不纳入版本库**（已加 `.gitignore`），部署时需在目标机同样跑一次该脚本。

> 二进制来自 GitHub releases（`rhasspy/piper 2023.11.14-2`），模型来自 HuggingFace（`rhasspy/piper-voices`）。下载需联网一次；之后运行时**完全离线**。

### 行为
- 装好后启动 dev，面试页会自动走本地 Piper，音色说明区显示"**当前：服务端本地神经网络合成**"。
- **音色下拉只有 3 个真实嗓音**：华嫣（女）、小雅（女）、朝文（男）——它们是 HF piper-voices 中仅有的中文神经网络模型，每个都是独立真实模型，音色/自然度确有差异。
- 优先级：本地 Piper（默认，检测到即启用）→ 云端 Edge（需联网，多数网络被拦）→ 浏览器本地合成（前端兜底）。可用 `TTS_PROVIDER=edge|mock|piper` 强制切换。

### 关于"音色数量 / 感情"
- **本地 Piper 仅提供 3 种中文神经网络嗓音**：华嫣（女）、小雅（女）、朝文（男）。它们的自然度远优于系统自带的基础机械嗓音，且是**神经网络级、有语气起伏**（不是完全无感情，但感情层次不如真人/微软云端丰富）。
- 这 3 个就是 Piper 全部的中文模型，**不存在第 4 种独立中文嗓音**。早期版本曾把 16 个 Edge 嗓音名映射到这 3 个模型的 `--length_scale` 变体，造成"大部分音色一样、且无感情"的假象——该假音色列表已彻底剔除，现在下拉里看到的每一个都是真实可用的模型。
- 想要**更多独立中文嗓音**：目前只能等 Piper 官方放出更多中文模型，或在本机系统安装微软中文神经语音包（见第三节）作为浏览器回退路径。
- 想要**最接近真人的感情层次**：让服务端能联网微软（极少数网络可行），此时走云端 Edge（页面显示"云端合成"）。但鉴于 403 普遍，不推荐作为默认。

## 二、为什么之前"切换没区别 / 重播没声音 / 机械"

这些是早期回退逻辑的缺陷，已全部修复（代码层，无需你操作）：

1. 音色下拉改为**动态枚举浏览器真实可用中文嗓音**并真正绑定，切换即时生效。
2. 重播复用同一音频元素、`currentTime=0`、正确 `onended`（旧逻辑在播放前就 `revokeObjectURL` 切断了音频源 → 没声音）。
3. 移除 `createMediaElementSource` 对 `<audio>` 的接管（该操作会独占音频流并导致元素哑火 → 整段听不到）。
4. 增加 `ttsBackend` 状态：页面明确显示"本地神经网络 / 云端合成 / 本机浏览器合成"。

> 注意：现在主链路是服务端音频（Piper WAV 或 Edge MP3），由 `<audio>` 播放；浏览器 `SpeechSynthesis` 仅作为最终兜底。开面前可点音色下拉旁的**「试听」**立即确认所选效果。

## 三、让"本机浏览器合成"也多音色、有感情（可选）

若想在前端回退路径（或你偏好浏览器合成）拿到更多独立中文嗓音，安装系统级微软神经语音包（免费、非插件）：

- Windows 11：设置 → 时间和语言 → 语言和区域 → 中文(简体) → 三点 → **语言选项** → 语音 → 点"**下载**"晓晓 / 云扬 / 云希 / 云健 / 晓辰 / 晓墨 / 云妮 / 云泽 等（名字含 `Online`/`Natural` 即神经嗓音）。
- macOS：系统设置 → 辅助功能 → 语音 → 系统语音 → 下载"中文(简体)"额外嗓音。
- 安装后刷新页面，音色下拉会列出这些真实嗓音；前端 `getVoices()` 能枚举到即生效。

验证装好没有（浏览器 F12 控制台）：
```js
speechSynthesis.getVoices().filter(v=>/zh/i.test(v.lang)).map(v=>v.name)
```
列表出现 `...Online (Natural)...` 的 `zh-CN` 嗓音即正确。

## 四、为什么"麦克风没弹窗 / 用不了"

`getUserMedia` 只在**安全上下文**可用，且代码要求先勾选"同意"。

### 必须做的三件事
1. **用 `http://localhost:<端口>` 访问**，勿用局域网 IP（如 `http://192.168.x.x:3000`）。`localhost` 是安全上下文才会弹授权框；局域网 IP 下 `navigator.mediaDevices` 可能为 `undefined`，代码已检测并提示。
2. **先勾选"同意开启麦克风"（语音）/ "同意开启摄像头与麦克风"（视频）**。未勾选时点麦克风按钮，代码会高亮该复选框并提示，不会触发授权（避免"无声无弹窗"困惑）。
3. 在系统弹窗选"允许"。若曾选"阻止"，点地址栏左侧 🎙/📷 图标改回"允许"。

### 局域网/真机测试（可选）
非 localhost 需 HTTPS。本地可用 `mkcert` 自签证书 + 域名（如 `ml.local`），给 dev server 配 `https` 后访问 `https://ml.local:3000` 即可授权。
