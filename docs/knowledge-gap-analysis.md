# MentorLoop 知识树覆盖度评估与缺漏清单

> 评估时间：2026-08-02 ｜ 参照基线：行业主流学习路径 / 面试大纲（MDN 前端路线、后端工程师大纲、SRE/云原生体系）
> 评估对象：data/seed-content.json 现有 33 章 / 245 知识点

## 一、评估方法

对现有知识树做覆盖度扫描，区分两类缺口：

- **A 类·章节级覆盖缺漏**：某重要主题完全没有章节（不是深度不足，是"根本没有"）。
- **B 类·格式/完整性缺漏**：知识点已存在，但前端有 17 个点缺失六段式中的某一段（进度核查已发现，属"质量不全"而非"主题缺失"）。

## 二、前端（15 章 / 84 点）

**整体判断**：HTML / CSS / JS / TS / 框架(React+Vue) / 工程化 / 浏览器原理 / 测试 / 性能 / 安全 / 部署 主干齐备，属"宽而稳"。

**A 类缺漏（建议新增章）**：
1. **Node.js 基础与服务端 JS** —— 模块系统、事件循环、fs·http·stream、BFF、SSR 运行时。前端工程化（Vite/Webpack 都跑在 Node 上）与全栈能力必备，目前完全空白。
2. **前端设计模式与架构** —— 观察者 / 模块模式 / 组合模式，以及微前端、模块联邦、Monorepo（pnpm workspace / Turborepo）。架构能力补齐。
3. **动画与交互动效** —— CSS 动画、Web Animations API、动画性能。目前仅有 fe-c5-s6「定时器与动画」基础。

**轻微缺口（可并入现有章，不必单开）**：
- HTTP 客户端工程化（拦截器 / 超时 / 重试 / 缓存）→ 并入 fe-c4 或 fe-c5。
- 数据可视化基础（Canvas / SVG / 图表库）→ 可选进阶章。
- i18n / Design Token / 主题体系 → 轻量。

## 三、后端（13 章 / 116 点）

**整体判断**：语言 / 并发 / JVM / 数据结构算法 / 网络 / OS / 存储 / 消息队列 / Spring / 微服务 / 分布式 / 系统设计 / 安全认证 主干非常完整，属"深而全"。

**A 类缺漏（建议新增章）**：
1. **后端测试与质量保障** —— JUnit / Mockito / TDD / 集成测试 / 契约测试 / 覆盖率。当前后端**零测试章节**，是明显缺口。
2. **API 设计与演进** —— REST 成熟度模型、GraphQL、gRPC、OpenAPI/Swagger、API 版本化。这是后端核心交付物，目前缺专章（仅在 be-msa / be-net 顺带提及）。
3. **NoSQL 与搜索** —— MongoDB / Elasticsearch / 文档·列族模型 / 全文检索。be-c2 只覆盖 MySQL + Redis，缺 NoSQL 全景与搜索场景。

**中等缺口**：
- 实时通信（WebSocket / SSE / 长连接）→ 可并入 be-net。
- Go / Node 后端语言（若平台定位多语言）→ 可选。

**已覆盖良好**：事务 / 锁体系 / MQ / 分布式事务 / 高并发实战 / 认证授权（be-sec 很完整）。

## 四、运维（5 章 / 45 点）

**整体判断**：Linux / 网络与 Nginx / 容器与 K8s / CI-CD 与可观测性 / SRE 安全与成本 主干齐备。

**A 类缺漏（建议新增章）**：
1. **数据库运维（DBA 视角）** —— MySQL / Redis 的备份恢复、主从复制运维、慢查询治理、参数调优、Redis 集群运维。be-c2 是开发视角，缺运维侧实操。
2. **基础设施即代码与公有云（IaC）** —— Terraform、AWS 或阿里云核心服务、对象存储、Serverless。现代运维核心能力，目前空白。

**中等缺口**：
- 配置管理与自动化（Ansible / Salt / Puppet）→ 传统自动化。
- 服务网格（Istio / Service Mesh）→ 进阶。
- 压测工具实操（k6 / JMeter / Locust）→ 并入 op-c5。
- 日志系统部署运维（ELK / Loki 实操）→ 并入 op-c4。

## 五、结论

- **整体**：三方向知识树**主干完整、深度达标**（后端尤其扎实），不存在"方向性大空白"。但各自有 **2–3 个 A 类章节级缺漏**，建议在 V2 前或 V2 中补齐。
- **优先级最高的 5 章（若补）**：①后端测试 ②API 设计 ③数据库运维 ④Node.js 基础 ⑤IaC/公有云。这 5 章价值最高、最常被面试/实战问及。
- **前置必做**：前端 17 个知识点六段式补全（B 类格式缺口）应**先于** V2 的内容增强，否则 V2 叠加在残缺骨架上。

## 六、给用户的决策选项

请确认以下走向（可多选）：

1. **只修 B 类**：先补前端 17 点六段式（小修，约 17 处编辑），知识树不动。
2. **补 A 类高优 5 章**：新增上述 5 章（每章约 6–10 个 v1 知识点），显著补全覆盖。
3. **补全部 A 类**：加上动画、微前端、NoSQL 搜索、配置管理、服务网格等，知识树扩到约 40+ 章。
4. **暂不改知识树**：维持现状直接进入 V2 增强（在已有骨架上做分级/互链/图示）。

建议路径：**1 → 2 → 4（V2）**，即先修格式、再补高优 5 章、最后做 V2。
